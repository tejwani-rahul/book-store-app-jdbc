# Book Store App

An online bookstore desktop application built with **Java Swing** and **MySQL**. The application provides functionality for both customers and administrators, allowing users to browse and purchase books while administrators can manage the bookstore.

## Technologies Used

* **Backend:** Java
* **Frontend:** Java Swing
* **Database:** MySQL
* **Database Connectivity:** JDBC

## Features

* Browse available books
* Search and manage books
* Customer and administrator functionality
* Book purchasing
* MySQL database integration using JDBC
* Desktop-based graphical user interface using Java Swing

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/tejwani-rahul/book-store-app-jdbc.git
cd book-store-app-jdbc
```

### 2. Set Up the Database

1. Create a MySQL database.
2. Import the provided SQL schema into the database.
3. Update the database connection details in the project configuration if required.

### 3. Run the Project

You can run the project directly from your Java IDE using the **Run** button.

Alternatively, compile and run it from the terminal:

```bash
javac BookStore.java
java BookStore
```
